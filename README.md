# InterviewKit

> Crack the interview, one pattern at a time.

A curated, interview-ready knowledge base of Java solutions — LeetCode problems,
design patterns, general coding challenges, and real company interview questions —
all organized by pattern, explained with intuition, and ready to browse as a website.

---

## What's Inside

| Section | Description |
|---|---|
| LeetCode Problems | 100+ problems organized by pattern (Array/String, Two Pointers, Sliding Window, Trees, etc.) — each with intuition, complexity analysis, and clean Java code. |
| Design Patterns | Singleton, Factory, Observer, Strategy, and more — implemented in idiomatic Java with real-world use cases. |
| General Coding Problems | Data structures from scratch, utility algorithms, and CS fundamentals. |
| Company Interview Questions | Real questions asked at FAANG and other companies, tagged by company and role. |

## Problem File Format

Every problem follows the same template so it stays easy to scan and learn from.

    # 0001 — Two Sum

    ## Problem
    ...

    ## Intuition
    ...

    ## Approach
    ...

    ## Complexity
    - Time: O(n)
    - Space: O(n)

    ## Java Solution
    (java code block)

    ## Edge Cases
    ...

## Features

- Pattern-based organization — learn why, not just how
- Consistent problem template — intuition, approach, code, edge cases
- Browsable website powered by Docsify (no build step)
- Company tags — filter by what FAANG actually asks
- Design patterns alongside algorithms
- Full-text search across every solution

---

## Live Website

The repo doubles as a static docs site using Docsify.

To preview locally:

    npx docsify-cli serve .

Then open http://localhost:3000
