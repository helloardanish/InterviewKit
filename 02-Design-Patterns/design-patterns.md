## 🗂️ Categories

### Creational

Patterns that deal with object creation mechanisms.

- [Builder](Builder/builder/)
- [Factory](Factory/factory/)
- [Singleton](Singleton/singleton/)

### Structural

Patterns that deal with object composition and interface adaptation.

- [Adapter](Adapter/adapter/)
- [Decorator](Decorator/decorator/)
- [Facade](Facade/facade/)
- [Proxy](Proxy/proxy/)

### Behavioral

Patterns that deal with communication and responsibility between objects.

- [Observer](Observer/observer/)
- [Strategy](Strategy/strategy/)

## 🎯 Why Design Patterns Matter in Interviews

Design patterns are an important part of Low-Level Design (LLD) interviews.

Interviewers want to see:

- You understand the **intent** of each pattern, not just its name.
- You can identify the right pattern for a given problem.
- You can explain trade-offs and design decisions.
- You can implement common patterns from memory.
- You can apply patterns to practical, real-world scenarios.

Each page in this section follows a consistent structure:

**Pattern → Intent → Core Idea → Java Code → Dry Run → Edge Cases → Interview Takeaway**
