## 🎯 Why design patterns matter in interviews

Design patterns are **50% of every LLD round**. Interviewers want to see:

- You know the **intent** of each pattern (not just the name)
- You can pick the right pattern for the problem
- You can explain trade-offs
- You can implement the common ones from memory

Each page in this section follows the same structure as the LeetCode problems: pattern → intent → core idea → Java code → dry run → edge cases → interview takeaway.
