# LeetCode 150

**Pattern-based Java solutions for coding interviews.**

This section organizes problems by the technique or data structure that commonly leads to the solution. Focus on understanding the pattern, not memorizing code.

## How to use this section

1. Read the problem and attempt it before looking at the solution.
2. Identify the pattern and explain why it applies.
3. Start with a straightforward solution, then optimize it.
4. Implement the solution in Java and test edge cases.
5. Record time and space complexity.
6. Revisit problems until you can solve and explain them independently.

## Recommended notes format

Each problem document should ideally include:

- Problem summary and examples
- Pattern and key observation
- Approach with a step-by-step explanation
- Java solution
- Time and space complexity
- Edge cases
- Alternative approach, where useful
